# Quick Start Guide - TextTypoOrganic02

## Getting Started in 30 Seconds

TextTypoOrganic02 creates beautiful, animated text shaped visualizations. Here's how to get started immediately:

### 1. Launch the Application

- First compile the OF project for your platform. (Tested Systems: Windows/macOS)
- Run `TextTypoOrganic02.exe` (Windows)
- The app displays an animated text shaped visualization in thescene

### 2. Key Commands

- Mouse click (left/right half window and left/right mouse buttons)
- Space: next preset.
- Enter: Toggle advanced mode
- H: Toggle help
- F: Toggle fullscreen/reset default
